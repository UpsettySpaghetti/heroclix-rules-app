# Heroclix Rules Assistant

A public Q&A page where visitors ask Heroclix rules questions and get answers generated by
Claude, grounded only in rules sources you've uploaded or linked - each answer cites which
source it came from. A password-protected `/admin` page lets you add or remove sources at any
time.

## How it works

1. You add sources (PDF/DOCX/TXT files, or web links) on the `/admin` page.
2. Each source is split into chunks, and each chunk is turned into an embedding (a numeric
   fingerprint of its meaning) via Voyage AI, then stored in a Supabase (Postgres) database.
3. When a visitor asks a question on the public page, the app embeds the question, finds the
   most relevant chunks by similarity, and asks Claude to answer using only those chunks -
   citing which source each part of the answer came from.

## One-time setup

You'll need four free accounts. None of these require a credit card for this app's scale.

### 1. Anthropic (generates the answers)

1. Go to [console.anthropic.com](https://console.anthropic.com) and sign up.
2. Add a small amount of credit (a few dollars covers a very large number of questions) or use
   any free trial credit offered.
3. Go to **API Keys** and create a key.

### 2. Voyage AI (turns text into searchable embeddings)

1. Go to [dashboard.voyageai.com](https://dashboard.voyageai.com) and sign up.
2. Go to **API Keys** and create a key. The free tier (200M tokens) is far more than this app
   will use.

### 3. Supabase (database + file storage)

1. Go to [supabase.com](https://supabase.com), sign up, and create a new project (pick any
   name/region, save the database password it generates somewhere safe - you won't need it for
   this app, but Supabase requires you set one).
2. Once the project is ready, open **SQL Editor**, paste in the contents of
   [`supabase/schema.sql`](supabase/schema.sql) from this repo, and run it. This creates the
   tables, search function, and a private storage bucket for uploaded files.
3. Go to **Project Settings -> Data API** and copy the **Project URL**.
4. Go to **Project Settings -> API Keys** and copy the **service_role** key (this is secret -
   it has full access to your database, so never put it in frontend code or share it).

### 4. Configure the app

1. Copy `.env.local.example` to a new file named `.env.local`.
2. Fill in `ANTHROPIC_API_KEY`, `VOYAGE_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` from
   above.
3. Set `ADMIN_PASSWORD` to a real password of your choosing - this protects the `/admin` page.

## Running it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) for the public Q&A page, and
[http://localhost:3000/admin](http://localhost:3000/admin) to add sources.

Add at least one source on `/admin` before asking questions - with no sources indexed, the app
will correctly say it doesn't know the answer rather than guessing.

## Deploying so it's public

This app is built to deploy on [Vercel](https://vercel.com) for free:

1. Push this project to a GitHub repository.
2. On Vercel, "Add New Project" and import that repository.
3. In the project's **Settings -> Environment Variables**, add the same five variables from your
   `.env.local`.
4. Deploy. Vercel gives you a public URL.

Note: Vercel's free tier limits a single request to about 4.5 MB, so very large PDF uploads
(above roughly that size) may need to be split into smaller files.
